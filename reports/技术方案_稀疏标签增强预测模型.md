# 咖啡店销量预测模型升级技术方案

> **版本**：v2.1 | **日期**：2026-10-12 | **状态**：生产候选合同已切换并完成离线验收

---

## 一、方案概述

### 1.1 当前状态

- **生产模型**：递归多步 Global LightGBM（L1 损失），五窗口滚动回测 MAE 2.633 / WAPE 37.9% / R² 0.607
- **瓶颈**：递归误差累积；77/240 个 SKU 日销量高度稀疏，模型无区别对待

### 1.2 升级内容

在现有直接多步 Tweedie 模型（MAE 2.442）基础上，新增 4 维起点安全稀疏标签特征，不改变模型架构和训练策略。

### 1.3 核心效果

| 指标 | 当前生产 | 推荐方案 | 提升 |
|------|:---:|:---:|:---:|
| MAE（杯） | 2.633 | **2.411** | -8.49% |
| WAPE | 37.92% | **34.72%** | -3.20pp |
| R² | 0.607 | **0.661** | +5.4% |
| 方向命中率 | 53.6% | **61.4%** | +7.8pp |
| 5 窗口胜出 | — | **5/5** | — |

**首次实现稀疏和稠密 SKU 子集同时改善**：稀疏品 MAE -4.8%（0.475 → 0.452），稠密品 MAE -1.05%（3.371 → 3.336），低销量 P25 区间改善 -11.4%。

## 二、方案架构

```
┌──────────────────────────────────────────────────────────────┐
│                    数据加载与预处理                            │
│  Coffee Shop Sales.xlsx + nyc_weather_2023_h1.csv            │
└──────────────────────┬───────────────────────────────────────┘
                       ▼
┌──────────────────────────────────────────────────────────────┐
│             起点前稀疏标签计算（仅执行一次）                     │
│  对每个 (store_id, product_id) 用首个预测起点前的数据计算：      │
│  • zero_rate = 零销量天数占比                                 │
│  • adi       = 非零间隔均值（无间隔 → 30）                     │
│  • mean_qty  = 日均销量                                       │
│  • is_sparse = zero_rate > 0.5 OR adi > 2.0                 │
└──────────────────────┬───────────────────────────────────────┘
                       ▼
┌──────────────────────────────────────────────────────────────┐
│              直接多步特征帧（按 horizon 独立构建）               │
│  T+1 帧 → T+2 帧 → ... → T+7 帧（各自起点安全）               │
│  基础特征：44 维历史/日历/天气/价格/身份                        │
│  + 稀疏标签：4 维（is_sparse, zero_rate, adi, mean_qty）      │
│  总计：53 维                                  │
└──────────────────────┬───────────────────────────────────────┘
                       ▼
┌──────────────────────────────────────────────────────────────┐
│     Global LightGBM (objective=tweedie, variance_power=1.3)  │
│  参数：1000 trees, LR=0.03, leaves=63, min_child=20,         │
│        subsample=0.9, reg_alpha=0.05, early_stopping=50      │
└──────────────────────┬───────────────────────────────────────┘
                       ▼
┌──────────────────────────────────────────────────────────────┐
│              门店校准 + 非负后处理                              │
│  起点前独立 7 天窗口估计门店偏差，收缩 50%，截断 [0.85, 1.20]   │
└──────────────────────────────────────────────────────────────┘
```

### 2.1 特征表

| 梯队 | 类别 | 维度 | 代表特征 |
|:---:|------|:---:|------|
| 一 | 历史滞后 | 6 | qty_lag_1/2/3/7/14/28 |
| 一 | 历史滚动 | 6 | qty_roll_mean/std_7/14/28d |
| 一 | 星期模式 | 1 | qty_dow_avg |
| 一 | 动态份额 | 1 | sku_share_28d（历史滚动） |
| 二 | 日历 | 7 | day_of_week, is_weekend, month, day_of_month, week_of_month, is_month_start/end |
| 二 | 季节 | 2 | season_code, week_of_season |
| 三 | 天气与节假日 | 19 | temperature/precipitation/wind/humidity/holiday 系列 |
| 四 | 价格 | 2 | price, price_vs_category_avg |
| 五 | 身份与步长 | 5 | store_id, product_id, category_code, product_type_code, forecast_horizon |
| **六** | **稀疏标签** | **4** | **is_sparse, zero_rate, adi, mean_qty** |

四个新增标签的信号语义：
- `is_sparse`：二值门控——模型是否启用稀疏模式
- `zero_rate`：零值频率——连续调制的稀疏程度
- `adi`：平均需求间隔——低频品的"典型安静期"
- `mean_qty`：历史均值——锚定低频品的低基数期望

### 2.2 训练与验证策略

| 维度 | 配置 |
|------|------|
| 验证方式 | 五窗口滚动回测（2023-05-27 / 06-03 / 06-10 / 06-17 / 06-24） |
| 每窗口切分 | 训练 → 验证（7d early-stopping）→ 校准（7d）→ 测试（7d） |
| 预测口径 | T+1～T+7 直接多步，不递归 |
| 校准 | 起点前独立 7 天窗口，门店偏差因子收缩后截断 |
| 稀疏标签 | 基于首个预测起点前数据计算，全期复用，严格无泄露 |

## 三、性能验证

### 3.1 整体指标

| 指标 | 当前生产 | 推荐方案 | 提升 |
|------|:---:|:---:|:---:|
| MAE（杯） | 2.633 | **2.411** | -8.49% |
| WAPE | 37.92% | **34.72%** | -3.20pp |
| RMSE | 3.913 | **3.636** | -7.08% |
| R² | 0.607 | **0.661** | +5.4% |
| 方向命中率 | 53.61% | **61.41%** | +7.8pp |
| 波动跟随比 | 0.138 | 0.186 | — |
| 5 窗口胜出 | — | **5/5** | — |

### 3.2 子集分层

| 子集 | 样本量 | 基线 MAE | 推荐 MAE | 改善 |
|------|:---:|:---:|:---:|:---:|
| 稀疏 SKU（77 个） | 2,695 | 0.475 | **0.452** | **-4.81%** |
| 稠密 SKU（163 个） | 5,705 | 3.371 | **3.336** | **-1.05%** |
| 低销量 P25 | — | 0.542 | **0.480** | **-11.40%** |
| 高销量 P90 | — | 7.696 | 7.761 | +0.84% |

- **5/5 窗口**稀疏和稠密子集均胜出；**6/7 预测步长**胜出
- **3/3 门店**、**9/9 品类** MAE 均改善，非少数商品或单一窗口拉动
- 低销量 P25 区间改善最显著（-11.4%），对补货决策价值最大

## 四、部署方案

### 4.1 已完成切换步骤

| 步序 | 内容 | 风险 |
|:---:|------|:---:|
| 1 | 直接分位数模型（P10/P50/P90）与有限样本 CQR | 已完成 |
| 2 | 53 维 TreeSHAP 对数链接到杯数尺度转换 | 已完成 |
| 3 | 天气、降雨、节假日 27 组 What-if 情景 | 已完成 |
| 4 | 五窗口 P10-P90 覆盖率验收（80.56%） | 已完成 |
| 5 | 逐预测 SHAP 加法验收（最大误差 7.46e-14） | 已完成 |
| 6 | Dashboard 切换至新预测、解释和风险数据 | 已完成 |
| 7 | 每小时只读巡检与后续服务端接入 | 待持续 |

### 4.2 向后兼容

- 现有递归模型保留为回退路径
- Dashboard 数据分片格式不变
- 仅增量 4 维特征 + 切换模型权重，不改变 API 合约
- 门店校准逻辑完全复用现有实现

### 4.3 已知限制

| 限制 | 影响 | 缓解 |
|------|------|------|
| 峰值预测弱化（P90 +0.84%） | 极端销量日可能低估 1～2 杯 | 天气预警做日内叠加修正 |
| 训练数据仅 181 天 | 季节性模式可能不充分 | 人工季节编码 + 假日增强 |
| 稀疏标签静态全期复用 | 新品上线后标签不更新 | 热重启时重新计算 |
